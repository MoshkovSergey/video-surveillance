# Video Surveillance System

Система видеонаблюдения на базе:

- Go;
- React;
- TypeScript;
- PostgreSQL;
- Docker;
- FFmpeg / MediaMTX.

## Назначение

Система предназначена для:

- просмотра живого видео с камер;
- записи видеоархива;
- хранения и поиска записей;
- регистрации событий;
- интеграции с внешними системами безопасности, включая пожарную автоматику.

## Структура

- `cmd/` — исполняемые приложения;
- `internal/` — прикладной код Go;
- `migrations/` — миграции базы данных;
- `web/` — фронтенд на React + TypeScript;
- `deployments/` — Docker и инфраструктурные файлы;
- `scripts/` — вспомогательные скрипты;
- `storage/` — локальное хранилище медиафайлов для разработки.
